DREIDING 타입 할당

SMILES와 좌표 파일로 moltemplate용 단일 분자 .lt 파일을 만듭니다.

RDKit 엔진을 준비하는 중입니다.
좌표 파일 (선택)
mol2, pdb, xyz 파일을 끌어다 놓거나 눌러서 고르십시오.

mol2는 좌표와 RESP 전하를, pdb·xyz는 좌표만 씁니다. 원자 순서는 자동으로 맞춥니다. 파일이 없으면 3D 구조를 새로 만듭니다.

.lt 출력

system.lt에서는 import "single_molecule.lt" 다음에 m = new MOL로 불러옵니다. 라벨 규칙은 moltemplate dreiding.lt()에서 미리 계산해 넣었고, 인터넷 연결 없이 동작합니다.
